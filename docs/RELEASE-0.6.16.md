# 云桥 AI 0.6.16

在 **桌面工作台 → 高级设置** 点击 **应用默认上下文**，可将 Codex 的上下文窗口（`model_context_window`）设为 272000 个 token，自动压缩阈值（`model_auto_compact_token_limit`）设为 244800 个 token，即窗口的 90%。已有自定义值仍可查看和修改。未配置时，页面会显示建议值，保存并重启 Codex 后生效。
