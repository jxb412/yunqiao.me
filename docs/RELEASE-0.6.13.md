# 云桥 AI 0.6.13

本版完善 Windows 客户端识别、CodeBuddy 历史续聊、Codex MCP 与 Skills 开关，以及网关与模型 SDK 的兼容性。

- **CodeBuddy 历史。** 历史页可查看、导出项目目录里的原生会话，并保留旧格式的阅读能力。符合续聊条件时，复制的命令会进入原项目目录，再恢复所选对话。
- **Windows 客户端。** 识别 Claude Desktop 官方安装器和 CodeBuddy CN。修复短路径和长路径指向同一份 Codex 会话文件时漏掉历史迁移的问题。
- **Claude Desktop 配置恢复。** 保留客户端生成的偏好和工作文件目录。遇到客户端重新加密的网关凭据时，保留配置和备份，提示从 Claude 的第三方推理设置中切换。
- **MCP 与 Skills。** 资源列表按 TOML 实际结构读取启停状态，支持带引号和点号的名称。切换可管理的条目时保留无关字段、注释和换行。
- **模型网关。** 原生非流式 Responses 文本可补齐缺失的引用数组。开启隐私遮蔽后，链接里经 URL 编码的占位符支持按请求还原，包括跨流式分片的内容。
- **供应商凭据。** 编辑已有供应商、将接口改到新的域名、端口或协议时，清除继承的 API Key 与认证头。请为新地址填写凭据，并核对余额查询设置。
- **后台目录。** 服务端源码改进了供应商导入记录的文本和属性显示，兼容已有目录中的颜色值，并为不支持的格式使用默认颜色。
- **局域网共享。** 在桌面端「系统设置 → 网关与隐私」可开启「共享期间保持电脑唤醒」。默认关闭，屏幕可按系统设置正常熄灭。

Windows x64 提供安装版、便携版和完整 ZIP。macOS 分别提供 Apple Silicon 与 Intel 的 DMG 和 ZIP。安装操作与系统要求见[安装说明](../INSTALLATION.md)，配置与历史恢复见[使用指南](../USER-GUIDE.md)。
