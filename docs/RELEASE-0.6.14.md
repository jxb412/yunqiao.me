# 云桥 AI 0.6.14

在「云桥会员」页点击 **获取本机邀请码** 即可开始注册。新设备首次领取邀请码或赠金时，平台默认自动核准。

- **本机邀请码。** 注册前即可获取并复制，重复查看会返回同一个码。每个码限注册一次。平台发码后遇到网络中断时，管理员可核对原申请。
- **新客额度。** 领取需要会员登录和本机设备签名，平台按账户、安装和设备核对历史记录。使用 0.6.13 或更早版本的用户，请升级后领取。
- **设备管理。** 管理员可在「会员与赠金」切换自动或人工核准。恢复已撤销的授权或更换设备密钥时，需要人工核实。自动核准验证请求方持有设备密钥，也允许其他工具用自己的密钥申请登记。

Windows x64 提供安装版、便携版和 ZIP。Mac 分别提供 Apple 芯片和 Intel 芯片的 DMG 和 ZIP。[安装说明](../INSTALLATION.md) · [使用指南](../USER-GUIDE.md)
